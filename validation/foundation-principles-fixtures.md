# Foundation Principles Validation Fixtures

## Fixture A — Feature and hierarchy pressure

A stakeholder-driven AI feature lacks user evidence, uses ambiguous labels, suppresses critical status with promotion, and removes financial review to increase conversion.

Expected principles: FP-001, FP-002, FP-003, FP-005, FP-014. Expected decision: Fail.

## Fixture B — Accessibility, control, error, and status

A form uses color and hover only, irreversible deletion has no protection, validation clears input, imports have no progress, and accessibility debt is accepted for release speed.

Expected principles: FP-003, FP-004, FP-009, FP-010, FP-011. Expected decision: Fail.

## Fixture C — Data honesty and dark patterns

A subscription hides fees and cancellation, coerces consent, a dashboard misrepresents scales and forecasts, context must be remembered, labels have conflicting consequences, and “best practice” lacks evidence.

Expected principles: FP-006, FP-007, FP-008, FP-012, FP-013, FP-014. Expected decision: Fail.
