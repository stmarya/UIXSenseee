# Visual Foundation Validation Fixtures

Use these controlled fixtures to regression-test VF rule routing, severity, cross-standard ownership, and conformance decisions.

## Fixture A — Hierarchy, layout, and density

An equal-weight card dashboard where promotion suppresses critical status, filters share unclear scope, mobile order reverses priority, sticky UI obscures focus at zoom, and compact mode removes grouping.

Expected primary rules: VF-001, VF-002, VF-003. Expected decision: Fail.

## Fixture B — Typography and color

An interface with inconsistent type roles, unreadably small labels, color-only links and status, insufficient contrast, direct-inversion dark mode, harmful increases shown as positive, and unsafe truncation.

Expected primary rules: VF-004, VF-005. Expected decision: Fail.

## Fixture C — Surfaces, icons, states, and themes

A glassmorphic interface with shadow-only boundaries, false affordance, ambiguous destructive icons, conflicting icon meanings, missing focus, conflicting states, unstable loading, missing rare states, and local token drift.

Expected primary rules: VF-006, VF-007, VF-008. Expected decision: Fail.
