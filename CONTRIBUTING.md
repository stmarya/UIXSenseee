# Contributing

1. Open a focused proposal describing the user problem.
2. Identify affected rule IDs and documents.
3. Use `templates/rule-template.md` for new rules.
4. Make requirements testable and technology-agnostic.
5. Add or update validation checks.
6. Document exceptions and compatibility impact.
7. Update `CHANGELOG.md` for normative changes.

Do not introduce a rule based only on personal visual preference. Provide usability, accessibility, domain, or user evidence.
