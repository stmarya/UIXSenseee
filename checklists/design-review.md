# Design Review Checklist

## Foundation

- [ ] Target users and primary tasks are defined.
- [ ] Assumptions are identified.
- [ ] Safety, accessibility, and task completion take priority over aesthetics.
- [ ] No manipulative or misleading pattern is present.

## Information Architecture

- [ ] Every major area maps to a user task.
- [ ] Labels use language users recognize.
- [ ] Categories, views, objects, and actions are distinguishable.
- [ ] Parent–child relationships are logical.
- [ ] Current location is visible without relying on color alone.
- [ ] Detail views provide a route back.
- [ ] Filters, sort, time range, and scope survive drill-down when appropriate.
- [ ] Categories at the same level have distinct meanings.
- [ ] Heading hierarchy matches content hierarchy.
- [ ] Exceptions are documented.
