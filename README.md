# UIXSenseee

UIXSenseee is a technology-agnostic UI/UX standard and review skill for humans and AI models. It prioritizes user needs, accessibility, honest data representation, predictable interaction, and measurable quality assurance.

## Objectives

- Provide normative UI/UX rules using **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT**, and **MAY**.
- Help AI models plan, generate, review, and improve interfaces consistently.
- Provide specialized guidance for dashboards and data-heavy products.
- Separate standards, operational checklists, reusable templates, and examples.

## Repository map

- `SKILL.md` — operational instructions for AI models.
- `AGENTS.md` — instructions for agents modifying this repository.
- `references/` — normative standards and supporting rationale.
- `checklists/` — review and release checks.
- `templates/` — reusable rule, audit, and exception formats.
- `audits/` — dated internal conformance and consistency audits.
- `validation/` — workflow validation reports and regression fixtures.
- `GOVERNANCE.md` — precedence, versioning, and change policy.
- `CHANGELOG.md` — record of normative changes.

## Rule levels

| Keyword | Meaning |
|---|---|
| MUST | Required for conformance |
| MUST NOT | Prohibited |
| SHOULD | Strong recommendation; exceptions need justification |
| SHOULD NOT | Strongly discouraged; exceptions need justification |
| MAY | Optional and context-dependent |

## Language

Normative statements use simple English for portability across AI models. Explanations may be bilingual. Technical terms remain in English when translation would reduce precision.
